# sf-chat-message

Одно сообщение чата. Перенесён из `simai/ui-chat` (решение владельца D31: компоненты
живут только в SIMAI Framework или ui-pro; перенос одобрен 2026-10-27) вместе с видом
сообщения, который там жил отдельно (`component/chat`: `render.js`, `people.js`,
`sanitize.js`, `chat.css`, `people.css`).

Два шаблона:

- **`default`** — ответ помощника (или его ожидание, отказ, ошибка) и вопрос человека
  с файлами (сообщение API.md Mirai24);
- **`person`** — сообщение разговора людей (пилот simai.chat): автор, группировка с
  соседями, своё — справа, время, «изменено», файлы, изменить и удалить.

Окно чата ставит `sf-chat-message` в ленту `sf-message-log` через её `renderMessage`;
сама лента о чате ничего не знает. Страница, которой нужно одно сообщение (превью),
ставит элемент сама.

## Что он делает и чего не делает

- **Разметка ответа**: HTML сервера чистится ещё раз в браузере (`SF.sanitizeHtml`
  Фреймворка, а пока пакет закреплён на паре без него — своя копия с тем же списком):
  абзацы, списки, цитаты, код, таблицы (с прокруткой), ссылки только http, https,
  mailto и корневые, заголовки трёх размеров (`h2`, `h3`, `h4`), зачёркнутое (`del`).
  Ссылка «Изображение: …» получает значок картинки и не загружает её. Код
  подсвечивает `SF.Highlight`, если он есть на странице, с кнопкой «Копировать код».
- **Источники**: сноски `[n]` в тексте становятся кнопками только там, где источник
  `n` есть, и не внутри кода; «Источники · N» в строке действий открывает список;
  сноска открывает его на своём источнике. Отрывок длиннее 160 знаков свёрнут до двух
  строк и раскрывается «Показать полностью».
- **Проверка**: «Проверен» — тихая отметка в строке действий; «Не полностью проверен»
  и «Ответ с оговоркой» — строка под ответом.
- **Ожидание**: строка этапа («Ищу в базе знаний», «Пишу ответ»…), а при остановленном,
  задержанном ожидании или без связи — строка с «Обновить».
- **Не ответ**: отказ, закрытое, ошибка (с «Повторить», пока не повторили), лимит —
  его словами, со временем обновления лимита второй строкой.
- **Память** (`notices`), **предложение изменения** — карточка `sf-change-confirm`
  пакета (её ответ `sf-change-confirm-answer` проходит через сообщение к окну, решает
  окно), **оценка** «Полезно» / «Не полезно» с вопросом «Что не так с ответом?»
  (причина и комментарий, «Отправить», «Не сейчас» или Escape), **копирование** ответа
  вместе со списком источников, **строка о том, как сделан ответ** (`summary`).
- **Уточнение задачи** (API.md v1.2, только при `features.brief`): вопросы с вариантами
  (рекомендуемый отмечен), «Свой вариант», несколько вопросов отвечаются вместе — через
  «; », пропущенный необязательный — «—»; карточка «Как я понял задачу» с «Да».
  Отвечать можно только у последнего ответа (`display.brief.live`); после — это запись,
  выбранный вариант отмечен. `brief.lead`, если есть, заменяет html.
- **Вопрос человека**: пузырь текста и файлы (плашка — `sf-chat-composer`); у
  отправленного файла с `href` имя — ссылка на скачивание; перед скачиванием адрес
  проверяется, и если файл удалён (404 или 410), плашка говорит «Файл удалён».
  Вопрос, заданный кнопкой (подтверждение, отмена, повтор), — тихая строка, а не пузырь.

Сообщение ничего не отправляет на сервер (кроме проверки адреса файла перед
скачиванием) и ничего не решает: каждое действие — событие, а смысл ему даёт хост.

## Подключение

```html
<sf-chat-message></sf-chat-message>
<script type="module">
  const message = document.querySelector('sf-chat-message');
  message.message = {id: 'msg_03', role: 'assistant', status: 'completed', text: 'Ежегодный отпуск — 28 календарных дней.'};
  message.addEventListener('sf-chat-message-rate', (event) => rate(event.detail.id, event.detail.value));
</script>
```

В ленте окна:

```js
log.renderMessage = (message, {view}) => {
  const node = document.createElement('sf-chat-message');
  node.features = features;
  node.display = view ?? {};
  node.message = message;
  return node;
};
```

Виджет сайта (без рантайма Фреймворка) вызывает вид напрямую:
`renderMessage(ctx, message, display)` из `js/view/message.js`, как в ui-chat.

## Настройки

Все три — свойства (или JSON-остров `data-sf-settings`); новая установка, даже того же
объекта, перерисовывает сообщение.

| Имя | Тип | По умолчанию | Что делает |
|:---|:---|:---|:---|
| `message` | объект | — | Сообщение (см. выше); без него элемент пуст. |
| `display` | объект | `{}` | Что знает хост, а сервер нет (в 0.3 — `view`): `wait`, `busy`, `feedback`, `retried`, `note` и `code`, `sources_open`, `brief`, `brief_draft`; для `person` — `own`, `first`, `last`, `showName`, `editing`, `askDelete`. Черновики (`feedback.draft`, `brief_draft`, `editing.body`) пишутся в этот объект. |
| `features` | объект | `{feedback: true, proposals: true, memory: true, brief: false}` | Что предлагает поверхность. |
| `template` | атрибут | `default` | `person` — сообщение разговора людей. |

## События

Всплывают, проходят границу shadow DOM; запросы отменяемы.

| Событие | `detail` | Когда |
|:---|:---|:---|
| `sf-chat-message-retry` | `{id}`; `{key}`; `{id, key, kind: file}` | «Повторить»: ответ; неотправленное сообщение человека; файл. |
| `sf-chat-message-check` | `{id}` | «Обновить» при остановленном или задержанном ожидании. |
| `sf-chat-message-rate` | `{id, value}`; `{id, value: down, reason, note}` | Оценка; «Отправить» в вопросе «Что не так». |
| `sf-chat-message-cancel` | `{id, kind: rate}` | «Не сейчас» или Escape в вопросе «Что не так». |
| `sf-chat-message-drafted` | `{id, reason, note}` | Изменился выбор или комментарий в вопросе «Что не так». |
| `sf-chat-message-toggle` | `{id, kind, open}` | Открыт или закрыт список источников (`sources`); у `person` — редактор (`edit`) и вопрос об удалении (`delete`). |
| `sf-chat-message-copied` | `{id, done}` | Ответ скопирован. |
| `sf-chat-message-submit` | `{id, text}` | Ответ на уточнение задачи уходит сообщением. |
| `sf-chat-message-save` | `{id, values: {body}}` | `person`: сообщение изменено. |
| `sf-chat-message-delete` | `{ids}` | `person`: удаление подтверждено. |

Старые имена до 2026-12-01 (`aliases.json`): общее `sf-chat-action {action, …}` версии
0.3 приходит следом за `retry`, `check`, `rate`, `cancel` (`feedback-skip`), `drafted`
(`feedback-draft`), `toggle` источников (`sources`), `copied` (`copy`) и `submit`
(`brief-answer`); свойство `view` читает и пишет `display`. Отмена общая.

|:---|:---|:---|

| `--sf-chat-message-text-color` | `--sf-on-surface` | текст |
| `--sf-chat-message-muted-color` | `--sf-on-surface-variant` | служебные строки |
| `--sf-chat-message-bubble-color` | `--sf-surface-container` | пузырь вопроса, тихие заливки |
| `--sf-chat-message-border-color` | `--sf-outline-variant` | края карточек, плашек, таблиц |

## Доступность

Сообщение — `article` с именем («Помощник», «Вы», у `person` — автор); ожидающий ответ —
`aria-busy="true"`. Кнопки копирования, оценки, источников и сносок названы; результат
копирования и оценки говорит вежливая область в строке действий; ошибка и обрыв связи —
`role="alert"`. В вопросе «Что не так» Enter отправляет, Escape убирает; в «Своём
варианте» Enter отвечает; в редакторе `person` Enter сохраняет, Shift+Enter — строка,
Escape — отмена; вопрос об удалении ставит фокус на «Отмена».
