# sf-chat-interlocutor

С кем разговор. Перенесён из `simai/ui-chat` (решение владельца D31: компоненты
живут только в SIMAI Framework или ui-pro; перенос одобрен 2026-10-27). Список
собеседников — серверный (у Mirai24 это `bootstrap.interlocutors`), элемент только
показывает его и сообщает о выборе. Разговор принадлежит одному собеседнику,
поэтому выбор другого — просьба о новом разговоре, которую выполняет хост (окно
чата).

## Что он делает и чего не делает

- Кнопка называет текущего собеседника. Нажатие открывает меню Фреймворка
  (`sf-context-menu`): пункты-радиокнопки, текущий отмечен.
- Свои помощники идут первыми, помощники баз знаний (`kind: "knowledge"`) — под
  своим заголовком, когда есть и те и другие. От восьми собеседников в меню
  появляется поиск.
- **Один собеседник — это имя, а не выбор.** Кнопка неактивна, без
  `aria-haspopup`, `aria-expanded` и описания, стрелка скрыта (класс
  `sf-chat-interlocutor--single`), действие `open` отвечает `refused single`.
- Разговор с собеседником, которого сервер больше не перечисляет (Mirai24 v1.1:
  ассистент администратора ушёл в личного, его старые разговоры остались),
  называется словом «Помощник», а не пустой строкой.
- Элемент **сам не меняет `value`**: выбор — событие, текущего собеседника
  назначает хост, когда новый разговор готов. Повторный выбор текущего ничего не
  сообщает.

Он ничего не загружает и не начинает разговоров.

## Подключение

```html
<sf-chat-interlocutor value="personal"></sf-chat-interlocutor>
```

```js
const picker = document.querySelector('sf-chat-interlocutor');
picker.options = bootstrap.interlocutors; // [{id, title, kind}]
picker.addEventListener('sf-chat-interlocutor-select', async (event) => {
  await startConversation(event.detail.id);
  picker.value = event.detail.id;
});
```

Сервер может напечатать список сразу, островом JSON внутри элемента (§5.4):

```html
<sf-chat-interlocutor value="personal">
  <script type="application/json" data-sf-settings>
    {"options": [{"id": "personal", "title": "Мой помощник"}, {"id": "shop", "title": "Поддержка магазина", "kind": "knowledge"}]}
  </script>
</sf-chat-interlocutor>
```

## Настройки и значение

| Имя | Тип | По умолчанию | Что делает |
|:---|:---|:---|:---|
| `options` | список (свойство) | `[]` | Собеседники: `[{id, title, kind?}]`; `kind: "knowledge"` — база знаний. `title` — текст, не разметка. |
| `value` | строка (атрибут и свойство) | `""` | id текущего собеседника. Управляемое значение: пишет хост. |

## Действия

Каждое отвечает исходом (`{outcome: 'applied'}` или `{outcome: 'refused', reason}`).

| Действие | Что делает |
|:---|:---|
| `setOptions(options)` (`set-options`) | То же, что свойство `options`; вызов версии 0.3 работает как был. |
| `open()` | Открыть меню, как нажатие. `refused single`, если собеседников меньше двух. |

## События

Всплывает, проходит границу shadow DOM, отменяемо.

| Событие | `detail` | Когда |
|:---|:---|:---|
| `sf-chat-interlocutor-select` | `{id}` | Выбран другой собеседник (глагол `select` словаря 1.1.5). |

Старое имя `sf-chat-interlocutor` (ui-chat 0.3) приходит вместе с новым, с тем же
`detail`, до 2026-12-01 (`aliases.json`); каждое использование отмечается в
`SF.deprecations`. Отмена любого из двух общая.

## Доступность

Кнопка с `aria-haspopup="menu"` и `aria-expanded="false"` с самого начала; её имя
— «Помощник: <название>», а описание (скрытое `sr-only`) говорит, что выбор начнёт
новый разговор, ещё до открытия меню. Пока меню открыто, `aria-expanded` ставит само
меню. Пункты — радиокнопки, текущий отмечен; клавиатура меню — своя у
`sf-context-menu` (стрелки, Home, End, буквы, Escape возвращает фокус на кнопку).

## Вид

Открытые переменные (задаются на элементе или выше, компонент их не ставит):

| Переменная | Что | По умолчанию |
|:---|:---|:---|
| `--sf-chat-interlocutor-color` | текст имени | `--sf-on-surface` |
| `--sf-chat-interlocutor-icon-color` | стрелка | `--sf-on-surface-variant` |
| `--sf-chat-interlocutor-hover-background-color` | фон кнопки под указателем | `--sf-surface-transparent-hover` |
| `--sf-chat-interlocutor-radius` | скругление кнопки | `--sf-radius-1` |
| `--sf-chat-interlocutor-height` | наименьшая высота кнопки | `--sf-ui-1--control-height`, под пальцем `--sf-ui-2--control-height` |

## Начальный вид

Поздних данных нет: собеседники приходят вместе с `value`. Начальный вид — закрытая
кнопка (меню печатается закрытым), снимки в `static/` снимает
`scripts/run-first-paint.mjs snapshot`. Элемент не читает часы, поэтому его снимки
не зависят от фиксированного времени инструментов начального вида.

Фикстура Studio — `studio.fixture.json`, дымовой сценарий — `studio.scenario.json`
(данные передаются вызовом `setOptions`). Проверки по манифесту — `probe.json`.
