# sf-editor

Единый редактор блоков страницы SIMAI: раскладка и текст — один документ и
один редактор (решение владельца от 2026-11-03). Режимов нет, есть глубина:
щелчок по тексту — печать, щелчок рядом — выбор блока, Esc — уровень вверх,
Enter — вниз. Построен на контрактах части A SIMAI Framework (пара
ui-a2ca21f06e0c): каталог и варианты, параметры раскладки как утилиты, наборы
параметров, блоки сайта, именованные места и данные из порта источников.

Элемент ничего не хранит: после каждого изменения он отправляет `change` с
новым документом, сохраняет хост.

## Данные

```js
editor.document = doc;           // Composition Document, профиль ui-layout
editor.types = [cardsType];      // свои типы блоков хоста
editor.renderers = {'site.cards': renderCards};
editor.editorManifests = [cardsEditor];
editor.siteBlocks = savedBlocks; // блоки сайта из конструктора
editor.words = {ru: {...}, en: {...}};
editor.rights = {layout: true, template: false, builder: true};
editor.theme = {name: 'brand', label: 'Фирменная', settings_url: '/admin/theme', defaults: {}};
editor.addEventListener('change', (event) => save(event.detail.document, event.detail.scope));
editor.addEventListener('sf-editor-block-save', (event) => keepBlock(event.detail.manifest, event.detail.words));
editor.connectPort({sources, fields, preview, saveBlock});
```

Страница с шаблоном сайта — `layout.regions` с областями `banner`, `main` и
`contentinfo`. Шапка и подвал — шаблон: они приглушены с замком и меняются
только явно, кнопкой «Изменить шаблон» (`edit-template`). `change` с
`scope: 'template'` — изменение шапки или подвала всех страниц.

## Права и тема

Права приходят от хоста, переключателя ролей в редакторе нет.
`layout: false` — автор пишет только внутри текстовых областей
(`layout.area`), остальное приглушено с замком и объяснением.
`reasons` заменяют объяснения замка словами хоста.

Тема только читается: её значения по умолчанию — один из уровней
происхождения значения, её атрибуты ставятся на нарисованную страницу.
`settings_url` ведёт туда, где тему меняют.

## Вставка, перемещение, колонки

Один каталог (вкладки «Текст» и «Блоки», группы, варианты с картинками,
поиск, избранное, недавние) открывается тремя путями: «+» между блоками, «/»
в пустой строке и библиотека слева (перетаскиванием или нажатием). Вкладка
выбирается по месту; вкладка, где ничего не подходит, скрыта.

Блок двигают за ручку с линией места, Alt+↑↓ у выбранного блока и
Alt+Shift+↑↓ во время набора. Сброс к боковому краю соседнего блока делит
место на колонки; «Разделить на колонки» есть в меню ручки и в панели.

## Параметры и данные

Панель справа показывает у каждого значения, откуда оно: тип, тема, вариант,
блок, экран. Переключатель экранов (компьютер, планшет, телефон) задаёт, для
какого экрана пишется значение, и показывает страницу на этом экране.
Вкладка «Данные» связывает блок с источником хоста через порт источников:
источник, сопоставление полей, сколько, текст на пустой случай, состояние
предпросмотра (данные, пусто, ошибка, загрузка) и связь с блоком той же
секции. Блок сам ничего не загружает.

## Конструктор блоков

«Создать свой блок» или «Сделать блоком сайта» открывает конструктор: блок
собирается из тех же частей, для автора открываются выбранные параметры,
блок сохраняется как блок сайта (`sf-editor-block-save`). Изменение блока
сайта сохраняется новой версией и переносит все его экземпляры на странице
(`upgradeComposed`), сохраняя тексты и значения автора.

## Результат

«Результат» показывает страницу как JSON, как HTML с классами утилит и как
Markdown текстовых областей; то же даёт действие `output`.

## Клавиши

| Где | Клавиша | Что делает |
| --- | --- | --- |
| страница | Enter / Esc | вниз / вверх по глубине |
| страница | ↑ ↓ | соседний блок |
| страница | Alt+↑↓ | переместить блок |
| страница | ⌫, ⌘D | удалить, дублировать |
| текст | Enter, ⌫ в начале | разделить, соединить |
| текст | / | каталог |
| текст | Alt+Shift+↑↓ | переместить блок, не прерывая набор |
| везде | ⌘Z, ⇧⌘Z | одна история для текста и структуры |
