# sf-editor

Единый редактор блоков страницы SIMAI: раскладка и текст — один документ и
один редактор (решение владельца от 2026-11-03). Режимов нет, есть глубина:
щелчок по тексту — печать, щелчок рядом — выбор блока, Esc — уровень вверх,
Enter — вниз. Построен на контрактах части A SIMAI Framework (пара
ui-a2ca21f06e0c): каталог и варианты, параметры раскладки как утилиты, наборы
параметров, блоки сайта, именованные места и данные из порта источников.

Элемент ничего не хранит: после каждого изменения он отправляет `change` с
новым документом, сохраняет хост.

## Данные

```js
editor.document = doc;           // Composition Document, профиль ui-layout
editor.types = [cardsType];      // свои типы блоков хоста
editor.renderers = {'site.cards': renderCards};
editor.editorManifests = [cardsEditor];
editor.siteBlocks = savedBlocks; // блоки сайта из конструктора
editor.words = {ru: {...}, en: {...}};
editor.rights = {layout: true, template: false, builder: true};
editor.theme = {name: 'brand', label: 'Фирменная', settings_url: '/admin/theme', defaults: {}};
editor.addEventListener('change', (event) => save(event.detail.document, event.detail.scope));
editor.addEventListener('sf-editor-block-save', (event) => keepBlock(event.detail.manifest, event.detail.words));
editor.connectPort({sources, fields, preview, saveBlock});
```

Страница с шаблоном сайта — `layout.regions` с областями `banner`, `main` и
`contentinfo`. Шапка и подвал — шаблон: они приглушены с замком и меняются
только явно, кнопкой «Изменить шаблон» (`edit-template`). `change` с
`scope: 'template'` — изменение шапки или подвала всех страниц.

## Панель и места хоста

Сверху одна строка: отмена и повтор, переключатель экранов по центру,
справка, результат и тема — кнопками со значком. Свои элементы хоста
(переключатель списка страниц, языка) ставятся в ту же строку через места
(slots) — второй строки у хоста нет:

```html
<sf-editor>
  <sf-button-icon slot="start" icon="menu" aria-label="Страницы"></sf-button-icon>
  <sf-dropdown slot="actions" size="1/2" aria-label="Язык"></sf-dropdown>
</sf-editor>
```

- `start` — в начале строки, перед отменой и повтором;
- `actions` — в конце строки, перед справкой, результатом и темой.

Элементы мест забираются при первом подключении элемента (как у
`sf-header-page`); добавленные позже ставятся через `setSlot(name, element)`.
Размер элементов в строке — `1/2`.

Название страницы и подпись под ним хост передаёт настройками `heading` и
`caption` — они стоят в начале строки, как в прототипе:

```html
<sf-editor heading="Главная" caption="Страница сайта · черновик"></sf-editor>
```

«Изменить шаблон» — тихая текстовая ссылка рядом, без значка.

Библиотека слева — разделы SIMAI Framework со значком и числом блоков
(`CATALOGUE_GROUPS`, `CATALOGUE_GROUP_TABLE`), избранное (пустое — с короткой подсказкой) и недавние сверху.
Раздел открывается на месте, с «Назад»; найденное поиском подписано
разделом. Варианты блока — карточки с картинкой из дерева варианта.

Страница — лист с тенью на спокойном фоне. Выбранный блок обведён, над ним —
плавающая панель: путь, ручка, вверх, вниз, копия, «Ещё». Панель справа —
значок, имя и раздел блока, вкладки «Параметры», «JSON», «HTML», поля в
группах «Содержимое», «Расположение», «Дополнительно»; у каждого поля —
точка происхождения значения, «Сбросить» и привязка SIMAI Framework мелким
моноширинным шрифтом.
«Сбросить» возвращает значение варианта, если блок вставлен вариантом, затем
темы и типа. У экземпляра блока сайта — только открытые конструктором
параметры, без «Дополнительных классов».

## Настройки страницы

Пока ни один блок не выбран, панель справа показывает настройки самой
страницы (1.2.0), если хост их передал свойством `pageSettings`
(`page-settings`) или разметкой в месте `page`:

```js
editor.pageSettings = {
  name: 'Главная', address: '/', status: 'черновик · изменения не опубликованы',
  template: {value: 'main', options: [{value: 'main', text: 'Основной: шапка и подвал'}, {value: 'none', text: 'Без шапки и подвала'}]},
  theme: {label: 'Обычная', settings_url: '/admin/site'},
  publish: {note: 'Пока страница не опубликована, посетители видят прошлую версию.'},
  history: {count: 12},
};
editor.addEventListener('sf-editor-page-change', (event) => savePage(event.detail.key, event.detail.value));
editor.addEventListener('sf-editor-page-action', (event) => event.detail.action === 'publish' ? publish() : openHistory());
```

Каждый ключ необязателен: чего нет, того нет в панели. Шаблон со списком
`options` — выпадающий список, без него — только название. Тема — название и
ссылка на её настройки. Редактор ничего не хранит: изменение и нажатие
приходят событиями, хост сохраняет и ставит `pageSettings` заново. Без
настроек и без места `page` панель показывает короткую подсказку.

## Права и тема

Права приходят от хоста, переключателя ролей в редакторе нет.
`layout: false` — автор пишет только внутри текстовых областей
(`layout.area`), остальное приглушено с замком и объяснением.
`reasons` заменяют объяснения замка словами хоста.

Тема только читается: её значения по умолчанию — один из уровней
происхождения значения, её атрибуты ставятся на нарисованную страницу.
`settings_url` ведёт туда, где тему меняют.

## Вставка, перемещение, колонки

Один каталог открывается тремя путями: «+» между блоками, «/» в пустой
строке и библиотека слева (перетаскиванием или нажатием). С 1.2.0 «+» и «/»
показывают тот же список разделов, что библиотека: раздел со значком и
числом блоков открывается на месте, «Назад» (или ← и Backspace в пустом
поиске) возвращает к разделам, найденное поиском подписано разделом. «/» в
тексте сразу открывает раздел «Текст». Тип с `catalogue.also_in` (например,
кнопка) стоит и в своём разделе, и в перечисленных; в поиске — один раз.
Раздел, где ничего не подходит месту, скрыт.

Блок двигают за ручку с линией места, Alt+↑↓ у выбранного блока и
Alt+Shift+↑↓ во время набора. Сброс к боковому краю соседнего блока делит
место на колонки; «Разделить на колонки» есть в меню ручки и в панели.

## Параметры и данные

Панель справа показывает у каждого значения, откуда оно: тип, тема, вариант,
блок, экран. Переключатель экранов (компьютер, планшет, телефон) задаёт, для
какого экрана пишется значение, и показывает страницу на этом экране.
Вкладка «Данные» связывает блок с источником хоста через порт источников:
источник, сопоставление полей, сколько, текст на пустой случай, состояние
предпросмотра (данные, пусто, ошибка, загрузка) и связь с блоком той же
секции. Блок сам ничего не загружает.

## Конструктор блоков

«Создать свой блок» или «Сделать блоком сайта» открывает конструктор: блок
собирается из тех же частей, для автора открываются выбранные параметры,
блок сохраняется как блок сайта (`sf-editor-block-save`). Изменение блока
сайта сохраняется новой версией и переносит все его экземпляры на странице
(`upgradeComposed`), сохраняя тексты и значения автора.

## Результат

«Результат» показывает страницу как JSON, как HTML с классами утилит и как
Markdown текстовых областей; то же даёт действие `output`.

## Клавиши

| Где | Клавиша | Что делает |
| --- | --- | --- |
| страница | Enter / Esc | вниз / вверх по глубине |
| страница | ↑ ↓ | соседний блок |
| страница | Alt+↑↓ | переместить блок |
| страница | ⌫, ⌘D | удалить, дублировать |
| текст | Enter, ⌫ в начале | разделить, соединить |
| текст | / | каталог |
| текст | Alt+Shift+↑↓ | переместить блок, не прерывая набор |
| везде | ⌘Z, ⇧⌘Z | одна история для текста и структуры |
