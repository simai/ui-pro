# sf-mail-letters

Письма человека в SIMAI — редакторе писем: поиск по названию, порядок и то, что
предлагает строка — «Открыть» и под ⋯ копия, переименование и удаление.
Перенесён из `simai/ui-mail` (`package/src/smart/mail-letters`, 0.1.0, коммит
750be03) по решению владельца D31 от 2026-10-29: продуктовые репозитории не
делают своих наборов компонентов, общие компоненты живут в ui-pro. Имя осталось
прежним.

Элемент не хранит писем и ничего не делает сам: он сообщает, что выбрал человек.

## Данные

```js
letters.letters = [
  {id: 'prj_1', title: 'Осенняя рассылка', at: '2026-10-29T08:00:00Z', blocks: 7},
  {id: 'prj_2', title: 'Приглашение', at: '2026-10-21T10:30:00Z', blocks: 4},
];
letters.setAttribute('current', 'prj_1');
letters.addEventListener('sf-mail-letters-open', (event) => openLetter(event.detail.id));
letters.addEventListener('sf-mail-letters-copy', (event) => copyLetter(event.detail.id));
letters.addEventListener('sf-mail-letters-rename', (event) => askNameAndRename(event.detail.id));
letters.addEventListener('sf-mail-letters-delete', (event) => confirmAndDelete(event.detail.id));
letters.addEventListener('sf-mail-letters-create', () => newLetter());
```

`at` — это момент, а не фраза: строка сама пишет «5 минут назад» на языке
страницы через `Intl.RelativeTimeFormat`. Число блоков — тоже на языке
страницы, с нужной формой по `Intl.PluralRules`: «1 блок», «4 блока»,
«7 блоков». Поэтому одно и то же письмо читается верно и по-русски, и
по-английски, а хосту не нужно знать язык.

## События

| Событие | Когда | `detail` |
|:---|:---|:---|
| `sf-mail-letters-open` | «Открыть» в строке | `{id}` |
| `sf-mail-letters-copy` | «Копия» под ⋯ | `{id}` |
| `sf-mail-letters-rename` | «Переименовать» под ⋯; новое название спрашивает хост | `{id}` |
| `sf-mail-letters-delete` | «Удалить» под ⋯; подтверждает и удаляет хост | `{ids: [id], id}` |
| `sf-mail-letters-create` | «Новое письмо» | `{}` |

## Поиск и порядок

`query` — поиск по названию, `order` — `changed` (сначала изменённые) или
`title` (по названию, с сортировкой по языку страницы). Поле и список внутри
элемента их записывают; хост может задать то же атрибутами или действиями
`search {query}` и `sort {order}` (другой порядок — `refused unknown`).

Если писем нет совсем — `sf-empty-state` «Писем пока нет». Если ничего не
нашлось по поиску — «Ничего не найдено»: это разные состояния, и человек видит,
какое из них его.

## Открытое письмо

`current` — id письма, открытого в редакторе. Его строка отмечена, говорит
«открыто сейчас» словами (не только цветом) и не предлагает «Открыть»; действие
`choose {action: 'open', id}` для него отвечает `refused current`.

## Клавиатура и доступность

Сначала панель — поиск, порядок, «Новое письмо», — затем у каждой строки
«Открыть» и ⋯ в порядке Tab; меню — `sf-context-menu` со своей клавиатурой.
Имя кнопки ⋯ — «Действия с письмом: <название>», чтобы две строки не звучали
одинаково. Удаление подтверждает хост: элемент ничего не спрашивает и ничего
не удаляет.

## Что изменилось при переносе

- `sf-mail-letters-new` теперь `sf-mail-letters-create` (глагол словаря 1.1.5).
  `sf-mail-letters-delete` несёт `{ids, id}`: `ids` — по словарю, `id` — как
  раньше. Элемент не выпускался, поэтому старых имён-псевдонимов нет.
- Методы `choose`, `search`, `sort` стали действиями; `sort` с неизвестным
  порядком теперь отказывает, а не сбрасывает порядок.
- Число блоков — одно слово `blocks-text` с формами `one`, `few`, `many`,
  `other` в `lang/*.json`; форму выбирает Фреймворк.
